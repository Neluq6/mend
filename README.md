mend applies the edits AI models write — unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files. It finds the lines each edit names at the first of three matching tiers (exact, trailing-whitespace-insensitive, fully whitespace-insensitive), tolerates drifted whitespace and indentation, and writes every change or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
